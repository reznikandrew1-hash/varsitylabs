# Varsity Labs site

Storefront + owner dashboard for shopvarsitylabs.com. Hosted on Railway, deployed automatically from this GitHub repo:
every push to `main` builds the site and goes live in about two minutes.

## Layout
- `src/varsity_labs.html` — the whole store (products, prices, copy, styles, scripts). Edit this to change the site.
- `src/varsity_coa.html`, `src/varsity_reps.html` — lab reports page and rep program page.
- `src/img/` — product photos (`p-<slug>.jpg`, 1200px) and thumbnails in `src/img/t/` (480px).
- `build_site.py` — turns `src/` into `public/` (store, reports, reps, catalog.json, sitemap) and `private/` (dashboard). Runs on every Railway build; run it locally with `python3 build_site.py` to preview.
- `server.js` — dependency-free Node server: store, checkout, owner dashboard, rep portal, customer accounts, QuickBooks + Zoho sync.
- `tools/` — one-off helpers (vial label stamping).

## Editing prices or products
Prices live in the `PRODUCTS` array near the top of the scripts in `src/varsity_labs.html` (`["Name", "Category", [["10mg", 89], ...], "note", "CODE"]`)
and are mirrored in the `P` object for product pages. Change both, commit, push. `catalog.json` (what checkout trusts) is regenerated by the build.

## Run locally
```
python3 build_site.py
DATA_DIR=/tmp/vl SESSION_SECRET=dev OWNER_ANDREW_PASSWORD=x OWNER_AIDEN_PASSWORD=y PORT=3178 node server.js
```

If `build_site.py` hangs, iCloud has evicted files under `src/img/`: run `brctl download ../img src/img/t` and rerun the build.
When vial photos change, bump the `?v=N` on every `img/p-*.jpg` / `img/t/p-*.jpg` reference (store + build_site.py) so browsers drop their 24h cache.

## Vial label wordmark
`tools/label_vials.py <src img dir> <out dir>` prints the maroon "VARSITY LABS" wordmark onto the blank white label of each
`p-*.jpg` photo (auto-detected, with hand placements in `tools/label_overrides.json`). The untouched originals are kept in
`the iCloud folder `img_originals_blank/``. Re-run it and regenerate `img/t/` thumbnails (480px, q70) if a photo is replaced.
